# lemon's NewTab

A purely static Chrome New Tab extension: clock + search bar + navigation cards + a slide-out settings panel,
all written in native HTML, CSS, and JavaScript. There’s no build process—just refresh the page after making changes to see the results.

---

## Instructions for Use

1. Open `chrome://extensions/` and enable "Developer Mode" in the upper-right corner;
2. Click "Load unpacked extension";
3. Select the `versions/v0.7.0/` (or any previous version) directory;
4. Open a new tab to see the results.
