## lemon's NewTab
<div dir="rtl">
ملحق صفحة جديدة في Chrome ثابت تمامًا: ساعة + مربع بحث + بطاقات التنقل + لوحة إعدادات قابلة للانزلاق،
مكتوب بالكامل بلغة HTML / CSS / JavaScript الأصلية، ولا تتطلب أي خطوات إنشاء، فما عليك سوى تحديث الصفحة بعد إجراء التعديلات لترى النتيجة.

---

## طريقة الاستخدام

1. افتح `chrome://extensions/`، وقم بتفعيل «وضع المطور» في الزاوية العلوية اليمنى؛
2. انقر على «تحميل الإضافات التي تم فك ضغطها»؛
3. اختر المجلد `versions/v0.7.0/` (أو أي إصدار سابق)؛
4. افتح علامة تبويب جديدة لترى النتيجة.
