# lemon's NewTab

Чисто статическое расширение для новой вкладки Chrome: часы + поле поиска + карточки навигации + выдвижная панель настроек,
всё написано на нативном HTML / CSS / JavaScript, без этапов сборки — достаточно обновить страницу после внесения изменений, чтобы увидеть результат.

---

## Способ применения

1. Откройте `chrome://extensions/` и в правом верхнем углу включите «Режим разработчика»;
2. нажмите «Загрузить распакованное расширение»;
3. выберите каталог `versions/v0.7.0/` (или любую версию из истории);
4. откройте новую вкладку, чтобы увидеть результат.
