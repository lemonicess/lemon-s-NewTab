# lemon's NewTab

完全に静的なChromeの新規タブ拡張機能：時計＋検索ボックス＋ナビゲーションカード＋スライドアウト可能な設定パネル。
すべてネイティブのHTML／CSS／JavaScriptで記述されており、ビルド工程は不要で、変更後にページを更新するだけで変更内容が反映されます。

---

## 使用方法

1. `chrome://extensions/` を開き、右上の「開発者モード」を有効にします。
2. 「解凍済みの拡張機能を読み込む」をクリックします。
3. `versions/v0.7.0/`（または任意の過去のバージョン）のディレクトリを選択します。
4. 新しいタブを開くと、効果が確認できます。
