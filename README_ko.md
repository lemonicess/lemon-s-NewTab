# lemon's NewTab

순수 정적 Chrome 새 탭 확장 프로그램: 시계 + 검색창 + 탐색 카드 + 슬라이드 방식으로 열리는 설정 패널,
모두 네이티브 HTML/CSS/JavaScript로 작성되었으며, 빌드 과정이 없어 수정을 마친 후 새로 고침만 하면 바로 결과를 확인할 수 있습니다.

---

## 사용 방법

1. `chrome://extensions/`을 열고, 오른쪽 상단에서 「개발자 모드」를 켭니다.
2. 「압축을 푼 확장 프로그램 불러오기」를 클릭합니다.
3. `versions/v0.7.0/`(또는 원하는 이전 버전) 디렉터리를 선택합니다.
4. 새 탭을 열면 결과가 표시됩니다.
