# lemon's NewTab

Una extensión totalmente estática para la nueva pestaña de Chrome: reloj + cuadro de búsqueda + tarjetas de navegación + panel de configuración deslizable,
todo escrito en HTML, CSS y JavaScript nativos, sin necesidad de compilar; basta con actualizar la página para ver los cambios.

---

## Instrucciones de uso

1. Abre `chrome://extensions/` y activa el «Modo de desarrollador» en la esquina superior derecha;
2. haz clic en «Cargar extensiones descomprimidas»;
3. selecciona el directorio `versions/v0.7.0/` (o cualquier versión anterior);
4. abre una nueva pestaña para ver el resultado.
