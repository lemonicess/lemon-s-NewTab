# lemon's NewTab

一个纯静态的 Chrome 新标签页扩展：时钟 + 搜索框 + 导航卡片 + 可滑出的设置面板，
全部用原生 HTML / CSS / JavaScript 写成，没有构建步骤，改完刷新即可看到效果。

本仓库由作者手工维护的 8 个版本快照整理而来，**每个版本对应一个 Git 提交**，
提交时间沿用原始快照的日期，`git log` 即为完整演进史。

---

## 目录结构

```
lemon's NewTab/
├── README.md                 # 本文件：项目说明 + 版本时间线
├── .gitignore                # 排除打包产物、密钥/私有配置、编辑器临时文件
├── assets/

└── versions/

    ├── v0.1.0-优化更新/              # manifest 0.1
    ├── v0.2.0-设置更新/              # manifest 0.2
    ├── v0.3.0/                       # manifest 0.3
    ├── v0.3.1/                       # manifest 0.3.1
    ├── v0.4.0-预发布版/              # manifest 0.4
```

每个版本目录都是一份**可直接加载的完整扩展**（`manifest.json` 就位于该目录根部），
各自保留当时的 `README.md` / 自定义 CSS 等附属文件。

## 使用方法

1. 打开 `chrome://extensions/`，右上角开启「开发者模式」；
2. 点击「加载已解压的扩展程序」；
3. 选择 `versions/v0.7.0/`（或任意历史版本）目录；
4. 新建标签页即可看到效果。

修改 `index.js` 顶部 `DEFAULT_CONFIG`（背景、间距、搜索引擎、导航分区与卡片）后，
重新加载扩展或刷新页面即可生效。各版本目录内的 `README.md` 有更细的自定义说明。

## 整理时所做的改动

**删除的冗余副本**

- `v.1.1(优化更新)/插件/NewTab/index.js`：孤立副本，缺 `index.html` / `index.css`，
  内容为 `v0.1.1` 的残缺版（少 4 行 `settings-locked` 相关代码），判定为误操作产物。
- `v0.1.3（v0.T.1转）/插件backup/插件/`：与同版本 `插件/` 仅 `index.js` 等少量差异的备份副本。
- 两个空目录：`v0.1.0(内测)/插件/newtTab`、`v0.1.1(优化更新)/源码`。

**去重与规范化**

- 三个版本（v0.4.0 / v0.5.0 / v0.7.0）里的 `pumpkin-8384698_960_720.jpg` 是同一文件
  （md5 一致），实体只保留在 `assets/`，原位置改为相对软链
  `../../assets/pumpkin-8384698_960_720.jpg`，保证每个版本目录仍可直接加载。
  若在软链不可用的环境（如 Windows 未开启开发者模式）使用，把图片复制回对应目录即可。
- `插件.crx` 重命名为 `lemon-newtab-0.2.0.crx`，并按 `.gitignore` 排除，不入库
  （可由 `v0.2.0-设置更新/` 源码重新打包）。

**安全清理**

- `v0.4.0-预发布版/index.html` 末尾残留了一段从网页保存时带进来的
  Cloudflare Web Analytics 埋点 `<script>`，其中含有指向该站点的 `data-cf-beacon` token。
  已整行删除，因此该 token 从未进入 Git 历史。
- 全仓库复查：无 API Key、访问令牌、私钥、账号密码等敏感信息；
  Bing 每日壁纸接口（`HPImageArchive.aspx`）本身无需密钥。

## 仓库说明

- 分支 `main`；8 个版本快照按时间顺序各一个提交，提交时间＝原始目录修改时间。
- 每个快照提交都打了同名 tag（`v0.0.0` 至 `v0.7.0`），可直接
  `git checkout v0.5.0` 回到任意历史版本；tag 状态下只含该版本的扩展目录，
  根目录 README 与 `.gitignore` 在最后的整理提交中补全。
- `.gitignore` 额外忽略 `*.crx`、`node_modules/`、`.env*`、`secrets.json`、
  编辑器与系统临时文件。
- 本项目无依赖、无构建脚本，`git clone` 后即可作为扩展加载使用。

```bash
git log --oneline --decorate   # 看完整版本演进
git checkout v0.5.0            # 回到任意历史快照
git checkout main              # 回到最新
```
