# lemon's NewTab

一个纯静态的 Chrome 新标签页扩展：时钟 + 搜索框 + 导航卡片 + 可滑出的设置面板，
全部用原生 HTML / CSS / JavaScript 写成，没有构建步骤，改完刷新即可看到效果。

---

## 使用方法

1. 打开 `chrome://extensions/`，右上角开启「开发者模式」；
2. 点击「加载已解压的扩展程序」；
3. 选择 `versions/v0.7.0/`（或任意历史版本）目录；
4. 新建标签页即可看到效果。
